# demo

The Terraform config that gets cloned during the magos [quickstart](https://magosproject.io/docs/getting-started/quickstart).

It plans. It prints a banner. That's the whole show.

```sh
git clone https://github.com/magosproject/demo
cd demo
terraform init
terraform plan
```
